# Table 2 (matched sparse-signal benchmark) — provenance

## Source

`experiments/table02_matched.py` (archived as `reproduce_table1_current120_sparcl.py`),
executed with default arguments:

```bash
python experiments/table02_matched.py
```

Sparse K-means is fitted through the R package `sparcl`, not through a Python
reimplementation. The two runs recorded in `DIVI_CSDA.ipynb` (cells 31 and 32)
produced identical results, confirming that the SPKM tuning arguments
`--spkm-nperms 10 --spkm-wbound-len 12` are the script defaults.

## A superseded variant

An earlier version of the driver, `reproduce_table1_current120.py`, computed the
SPKM active set in Python rather than through `sparcl`. It agrees with the
`sparcl` run on every quantity except the SPKM support F1, where it gives
0.185 (0.002) and 0.200 (0.006) instead of 0.184 (0.002) and 0.190 (0.003).
The manuscript reports the `sparcl` values, so the Python variant and its
outputs are **not** included in this repository.
